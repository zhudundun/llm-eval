Evaluate the AI agent's solution to a data-analysis task.

unsupported_claim. If stderr shows an error or the code did not execute, that is a

================================================================================
SELF-VALIDATION PROTOCOL

You have a `run_python` tool that executes Python in the directory containing the CSV.
Follow TWO steps before judging:
STEP 1 -- THINK: Decide what to recompute to check the agent's answer. State your plan.
STEP 2 -- DO: Call run_python to load the CSV ('{file_name}') and INDEPENDENTLY recompute
the answer yourself. Compare your computed value to the agent's answer. You may call
run_python more than once if needed. Do NOT trust the agent's stdout -- compute it fresh.
Then call record_judgment with your verdict, your own self-derived answer, and whether it
agrees with the agent.

Notes on using `run_python`:
- The CSV is in the current working directory; load it directly, e.g.
  `import pandas as pd; df = pd.read_csv('{file_name}')`.
- Always `print(...)` the values you want to see; only stdout/stderr are returned.
- Recompute the answer from scratch using your own correct method. Do not copy the
  agent's code blindly -- if the agent's method is wrong, your independent computation
  should reveal the correct value.
- If you genuinely cannot validate (e.g. the file is unreadable or the task is
  underspecified), set self_validation_agrees to "could_not_validate" and explain.

================================================================================
SCORING RUBRIC

Score each dimension on an integer 1-5 scale:
  1 = wrong or unusable
  2 = major issues
  3 = partially correct
  4 = mostly correct
  5 = correct and well-supported

Dimensions:
- task_success_score:        Did the final answer actually solve the task as asked?
- code_correctness_score:    Was the code logically correct and executable?
- data_handling_score:       Did the agent load, filter, aggregate, join, group, and
                             transform the data correctly?
- statistical_validity_score: Did it use appropriate math/statistics (no invalid
                             assumptions, no overclaimed causality)?
- reproducibility_score:     Could the answer be reproduced exactly from the code and
                             logs alone?
- final_answer_quality_score: Was the answer clear, in the requested format, and not
                             over-explained?
- reasoning_quality_score:   Was the method reasonable, justified, and supported by the
                             data?

Use YOUR OWN recomputed value as the primary evidence for task_success_score and
final_answer_quality_score: if your independent computation disagrees with the agent's
answer, the agent did not solve the task correctly.

================================================================================
CRITICAL ERRORS

Record any concrete failures in `critical_errors`. Each entry has:
  - type:     one of the FAILURE_TYPES below
  - severity: "low" | "medium" | "high"
  - explanation: a short, specific description grounded in the code/logs/data

FAILURE_TYPES (use these exact strings, nothing else):
  wrong_answer, wrong_filter, wrong_aggregation, wrong_join, wrong_groupby,
  wrong_sorting, wrong_column, wrong_unit, rounding_error, missing_value_error,
  data_leakage, code_execution_error, timeout, hallucinated_column, unsupported_claim,
  incomplete_answer, format_error

If there are no critical errors, return an empty list.

================================================================================
OUTPUT

Call the `record_judgment` tool exactly once with your verdict. Provide every score as
an integer 1-5, the full list of critical_errors, an overall_pass boolean (your holistic
judgment of whether the answer should be accepted), a confidence between 0 and 1, and a
concise judge_explanation that justifies the verdict by citing specific evidence from
the code, stdout, dataset summary, or your own recomputation.

Also provide the three self-validation fields:
  - self_derived_answer:     the value YOU computed via run_python (e.g. "mean_fare=34.65").
  - self_validation_agrees:  "agree" if your value matches the agent's, "disagree" if it
                             does not, "could_not_validate" if you could not recompute it.
  - validation_summary:      a short description of HOW you validated (what you loaded,
                             what you computed, and the comparison result).
